# DaDb schemas

Planned: JSON schemas of the DaKanji formats' extensions to Yomitan
(`dakanji-dictionary`: `audio_list.json`, `dakanji-examples`: example banks, `dakanji-audio`: `index.json` and `entries.json`).

DaLang owns these schemas, they will be published with the DaLang website.
Once they are, they are synced from there like the Yomitan schemas in `../yomitan/`.
Until then `validate.py` checks only the layout of these files, their content is not validated.
