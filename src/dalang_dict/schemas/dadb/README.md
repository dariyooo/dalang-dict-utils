# DaDb schemas

JSON schemas of DaLang's extensions to the Yomitan format (examples, audio, `audio_list.json`).

DaLang owns these schemas, so they are vendored by hand from the DaLang repo
(`dart_packages/da_db/schemata/`, later published in the DaKanji manual) whenever they change.
They are not synced automatically like the Yomitan schemas in `../yomitan/`.

Record the DaLang commit they were copied from in a `SOURCE.json` next to them.
